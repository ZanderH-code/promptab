# Bundled fonts

These fonts ship inside the extension (latin subset, served from the package itself, never from the network). All are licensed under the SIL Open Font License 1.1; the full texts are in [`licenses/fonts/`](licenses/fonts).

| Font | Used as | Source |
| --- | --- | --- |
| Barlow Condensed | condensed tech display font | `@fontsource/barlow-condensed` |
| Cormorant Garamond | elegant serif display font | `@fontsource/cormorant-garamond` |
| Outfit | geometric sans-serif | `@fontsource/outfit` |
