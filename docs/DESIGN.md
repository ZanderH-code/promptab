# Minimal New Tab 美学设计指南

日期：2026-10-31  
配套文档：[PLAN.md](../PLAN.md)。本文是所有界面、预设主题以及 AI 生成内容的设计依据；其中 §10 会原样嵌入「AI 提示包」。

---

## 1. 设计理念

**一句话：安静的工作台。** 打开新标签页的那一秒，用户要的是「去哪里」，不是「看什么」。界面应当退后，内容和用户自己的选择在前。

四个关键词：

| 关键词 | 含义 | 反面 |
| --- | --- | --- |
| 安静 | 低饱和底色，一个强调色，默认无持续动画 | 多彩渐变、跳动的组件、通知角标 |
| 克制 | 每屏最多一个视觉焦点（通常是时钟或搜索） | 时钟、天气、名言、待办同时抢眼 |
| 有质感 | 细边框、柔和阴影、精确的字距与对齐 | 粗边框、默认浏览器控件、像素错位 |
| 属于你 | 任何视觉决定都能被覆盖，且覆盖后依然协调 | 改一个颜色整页失衡 |

「属于你」是本项目区别于一般新标签页的部分：**默认好看只是起点，系统要保证用户和 AI 改动之后也难以变丑**。手段是设计令牌（§3）加上质量护栏（§8）。

## 2. 现状评审（2026-10-31，基于 1440×900 与 400px 宽实测）

已经做对的：深青底色 `#102932` 配薄荷强调色 `#90d5cd` 气质统一；时钟 300 字重配负字距，层次清楚；设置抽屉中的开关、滑杆和下拉框已统一为强调色驱动的圆角控件；窄窗口能自动重排。

需要修正的问题，按影响排序：

1. **宽屏比例失衡**：`.desktop` 宽 `min(1200px, 88%)`，搜索框只有 620px，快捷方式按 6 列铺满 1200px。只有一两个网站时左侧显得空，整体不像一个整体。→ 引入统一的 `--mnt-content-width`，网格宽度跟随内容宽度，列宽固定、列数由数量与宽度推导（§4）。
2. **硬编码颜色绕过主题**：`#8885`、`#ffffff20`、`#282c30` 等散落在 CSS 中；下拉框选中色写死为 `#90d5cd`，改了强调色也不会跟着变。→ 全部改为语义令牌（§3.1），并加一条 lint 规则禁止组件 CSS 出现字面颜色值。
3. **Unicode 符号当图标**：`⚙ ⌕ ↗ ＋ ×` 在不同字体下大小、基线、粗细都不一致（Windows 上 `⌕` 尤其明显）。→ 换成同一套 SVG 图标（Lucide，1.5px 线宽，§6）。
4. **装饰文案占位**：`YOUR SPACE, YOUR PACE` 和左上角 `MINIMAL / NEW TAB` 字号只有 10px，既不可读，又不承担功能。→ 改为可选的「问候语」组件，默认关闭；品牌标识只在设置面板出现。
5. **设置与编辑混在一起**：打开设置抽屉即进入编辑模式，每个网站下方出现「编辑 ← → ×」四个文字按钮，视觉嘈杂；抽屉遮罩不拦截点击，点击外部不会关闭。→ 拆成「设置面板」与「编辑模式」两个状态（§5.6）。
6. **设置抽屉是一条长列表**：十几个区块垂直堆叠，没有分组导航和搜索，选项一多就找不到。→ 分区标签页加搜索（§5.5）。
7. **字体声明与实际不符**：CSS 写的是 `Inter`，但没有打包，实际回退到 Segoe UI 或微软雅黑。→ 明确系统字体栈；如需特色字体，本地打包少量可变字体（§3.2）。
8. **时钟数字会抖动**：比例数字在每分钟变化时宽度改变，整行左右轻微晃动。→ `font-variant-numeric: tabular-nums`。

## 3. 设计令牌

所有视觉值都来自令牌，令牌以 CSS 自定义属性 `--mnt-*` 暴露。它们也是 **CSS API 的一部分**：AI 和用户写的 CSS 只应使用这些变量，而不是重新发明颜色。

### 3.1 颜色

用户和主题包只需给出 **5 个基础色**，其余由系统在 OKLCH 色彩空间中推导，保证任何组合都有完整、协调的层级。思路借鉴 nightTab 的「主色 + 对比度区间 + 阶数」，但改用感知均匀的 OKLCH，阶梯更平滑。

| 基础令牌 | 用途 | 推导出的令牌 |
| --- | --- | --- |
| `--mnt-bg` | 页面底色 | `--mnt-bg-elevated`（亮度 +4%） |
| `--mnt-surface` | 面板、对话框、菜单 | `--mnt-surface-hover`、`--mnt-surface-active` |
| `--mnt-text` | 主要文字 | `--mnt-text-muted`（与背景混合 55%）、`--mnt-text-faint`（35%，仅用于装饰） |
| `--mnt-accent` | 强调色（焦点、选中、关键数字） | `--mnt-accent-soft`（12% 透明，用于底色）、`--mnt-accent-strong`（hover）、`--mnt-on-accent`（自动选黑或白，保证对比） |
| `--mnt-danger` | 删除、错误 | `--mnt-danger-soft` |

另有固定公式生成的中性层：`--mnt-border`（文字色 12%）、`--mnt-border-strong`（22%）、`--mnt-overlay`（遮罩）、`--mnt-shade-1…9`（从背景到文字的 9 阶插值，供 AI 自由取用）。

规则：

- 一屏只出现一个强调色。快捷方式的自定义色只作用于自身图标，不扩散到其他界面。
- 正文对比度 ≥ 4.5:1，大字（时钟）与图标 ≥ 3:1；不达标时设置面板显示警告，主题包导入时给出提示（§8）。
- 浅色主题不是深色的简单反相：浅色背景偏暖（纸感），阴影更淡，边框更明显。

### 3.2 字体

| 令牌 | 默认值 | 说明 |
| --- | --- | --- |
| `--mnt-font-ui` | `system-ui, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif` | 界面文字，中文优先清晰 |
| `--mnt-font-display` | 同上 | 时钟、标题；预设可改为衬线或等宽 |
| `--mnt-font-mono` | `ui-monospace, "Cascadia Mono", Consolas, monospace` | 终端风格预设、代码 |

可选字体族名：`system`、`serif`（`"Noto Serif SC", "Songti SC", Georgia, serif`）、`mono`、`rounded`（`"HarmonyOS Sans", ui-rounded, system-ui`），以及用户上传的本地字体（存在 IndexedDB 中，见 PLAN §5.2）。**默认不从网络加载字体。**

字号阶梯（基准 14px，比例约 1.25），用 `--mnt-scale` 整体缩放（对应 nightTab 的 layout size）：

| 令牌 | 尺寸 | 用途 |
| --- | --- | --- |
| `--mnt-text-xs` | 11px | 角标、快捷键提示 |
| `--mnt-text-sm` | 12px | 网站名、辅助说明 |
| `--mnt-text-md` | 14px | 正文、输入框 |
| `--mnt-text-lg` | 18px | 设置分区标题 |
| `--mnt-text-xl` | 24px | 对话框标题 |
| `--mnt-text-clock` | `clamp(64px, 10vw, 128px)` | 时钟 |

时钟：字重 200–300，字距 -0.04em 至 -0.07em，`tabular-nums`。中文不使用负字距，大写英文小字使用 +0.12em 字距。

### 3.3 间距、圆角、阴影、材质

- **间距**：4px 基数，阶梯为 `4 8 12 16 24 32 48 64 96`，令牌为 `--mnt-space-1…9`。组件内部用 1–4，组件之间用 5–7，区域之间用 7–9。
- **密度**：`compact` / `comfortable`（默认）/ `spacious`，通过 `--mnt-density`（0.8 / 1 / 1.25）统一乘以间距。
- **圆角**：用户只调一个 `--mnt-radius`（0–28px，默认 14px），各元素按比例取值：图标为 radius，面板为 radius×1.15，输入框为 min(radius, 999px)，菜单项为 radius×0.6。图标形状（圆、圆角方、方）独立设置。
- **阴影**：一个强度值 `--mnt-shadow`（0–100）映射到三级：`--mnt-elev-1`（悬停卡片）、`--mnt-elev-2`（菜单）、`--mnt-elev-3`（对话框、抽屉）。深色主题中阴影主要靠背景亮度区分，浅色主题中主要靠阴影本身。
- **材质（玻璃）**：`--mnt-glass`（0–100）控制面板的半透明度与 `backdrop-filter: blur()`。默认 0，只在有壁纸时推荐开启；用户开启「减少透明度」时强制为 0。

### 3.4 动效

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--mnt-dur-fast` | 120ms | 悬停、按下 |
| `--mnt-dur-base` | 200ms | 菜单、开关 |
| `--mnt-dur-slow` | 320ms | 抽屉、对话框、主题切换 |
| `--mnt-ease` | `cubic-bezier(.2,.7,.2,1)` | 进入 |
| `--mnt-ease-exit` | `cubic-bezier(.4,0,1,1)` | 退出 |

只对 `transform`、`opacity`、`color`、`background-color` 做动画。页面加载时不放入场动画，新标签页必须「瞬间出现」。`prefers-reduced-motion` 时所有时长为 0。

### 3.5 层级（z-index）

`base 0 → widget 1 → edit-overlay 10 → menu 20 → drawer 30 → dialog 40 → toast 50 → safe-mode-banner 60`。用户 CSS 不应改变 z-index；护栏层保证设置入口始终可点（PLAN §4.6）。

## 4. 版式与布局

- **内容宽度**：`--mnt-content-width` 默认 `min(960px, 88vw)`，所有区域共享这一宽度，避免搜索框、网格、标题宽度各不相同。
- **九宫格对齐**：整体内容块在视口中按九宫格对齐（借鉴 nightTab 的 `alignment`），默认「中-中」偏上 4vh，视觉重心落在黄金分割附近。
- **快捷方式网格**：列宽固定为 `图标尺寸 + 2×space-4`，用 `repeat(auto-fill, …)` 并以 `justify-content: center` 居中。用户设定的「列数」作为上限，而不是强行拉宽列。网站少时整组居中、紧凑，网站多时自然换行。
- **垂直节奏**：时钟 → 日期 8px，日期 → 搜索 48px，搜索 → 网站区 56px；乘以密度系数。
- **断点**：`narrow < 640px`（单列堆叠、图标上限 64px、列数上限 4），`medium 640–1024px`，`wide > 1024px`。布局区域可以按断点覆盖（PLAN §6.3）。
- **安全区**：四周最小留白 `space-6`；设置入口固定在右上角或右下角，不随布局移动。

## 5. 组件规范

### 5.1 时钟与日期

- 默认格式为 `HH:mm`，可选秒、12 小时制、分隔符样式（`:`、`·`、空格）、分隔符是否闪烁（默认不闪）。
- 日期默认为「10月31日 星期六」，年份默认隐藏，英文为 `Saturday, October 31`。
- 可选问候语（「晚上好，{名字}」），字号为 `text-lg`，颜色为 muted，默认关闭。

### 5.2 搜索框

- 高度 52px（乘以密度），全圆角或跟随 `--mnt-radius`，背景为 `surface` 的 60%（有壁纸时加 glass），边框为 `--mnt-border`，聚焦时边框变为强调色，并加 3px 的 `accent-soft` 外环。
- 左侧放引擎图标，可点击切换引擎；右侧仅在未聚焦时显示 `/` 快捷键提示，输入后提示变为回车图标。
- 占位文字使用 muted，不写口号（用「搜索或输入网址」，不用「搜索你想知道的」）。
- 输入内容像网址时，回车直接打开该网址。

### 5.3 快捷方式

- **结构**：图标板 + 名称。图标板尺寸为 `--mnt-icon-size`（40–120），名称最多一行、超出省略，hover 时用 `title` 显示全称。
- **favicon 处理**：各网站 favicon 风格差异很大，所以统一放在「图标板」上：板色默认为 `surface-hover`，可选「取网站主色的 15%」（从 favicon 提取主色）。favicon 占板面 55%，居中。低分辨率 favicon（≤16px）自动改用文字图标，避免模糊。
- **文字图标**：取名称首字（中文）或首字母（英文），字重 500，颜色为板色的高对比版本。
- **状态**：悬停时上移 2px 并加 elev-1；按下时 scale(0.97)；键盘焦点为 2px 强调色外环（offset 3px）；拖动时原位留虚线占位，被拖项为 elev-3 且半透明 90%。
- **样式变体**（对应 nightTab bookmark style）：`tile`（默认，图标在上、名称在下）、`list`（图标在左、名称和域名在右）、`minimal`（只有文字）、`card`（带背景卡片，可显示网址）。

### 5.4 书签分组

分组标题为 `text-sm`、字距 0.08em、muted，右侧显示细线和数量（保留现有设计语言）。分组可折叠，折叠动画只改变高度和透明度。空分组显示虚线框和「拖入或添加网站」。

### 5.5 设置面板

- **形态**：右侧抽屉，宽 420px，窄屏时全屏。顶部是搜索设置项的输入框，下面是分区标签。
- **信息架构**：`外观`（主题预设、颜色、字体、圆角阴影）· `背景` · `布局` · `组件` · `网站与分组` · `搜索` · `AI 与主题包` · `数据`（备份、历史、重置）· `关于`。
- **主题预设**用缩略卡片网格展示，卡片本身用该主题的令牌渲染，形成真实预览（借鉴 nightTab 的 preset tile）。
- **控件**：每行「标签 — 控件」；滑杆旁显示数值，可点击后直接输入；任何改动即时生效，并在顶部显示「撤销」toast，保留 6 秒。
- 每个分区底部都有「恢复本区默认」，不再只有全局重置。

### 5.6 编辑模式

- 通过设置面板的「编辑桌面」、右键菜单或快捷键 `E` 进入。进入后顶部出现一条浮动工具栏：添加网站、添加分组、添加组件、完成。
- 每个组件和网站在 hover 时显示角落小工具条（图标按钮：编辑、删除），不再常驻文字按钮。
- 拖动手柄只在编辑模式出现。组内排序支持键盘拖动（空格拾起、方向键移动、Enter 放下）；跨组移动提供「移动到分组」菜单与对话框，作为拖动的键盘可操作替代。
- 布局区域在编辑模式下显示 1px 虚线轮廓和区域名，方便用户理解 AI 写的 `areas`。

### 5.7 右键菜单、对话框与 toast

- 菜单项高 36px，带图标，危险项用 danger 色并放在最后，前面加分隔线。
- 对话框最大宽 480px，标题使用 `text-xl` 字重 500，主按钮放在右侧（强调色实心），次按钮为描边按钮。
- 删除改用「撤销 toast」，不再弹 `confirm()`：立即删除，6 秒内可撤销。不可逆操作（重置全部、清空历史）才使用确认对话框，并要求明确的按钮文字（「重置全部设置」，而不是「确定」）。
- toast 显示在底部居中，info 和 error 两种样式，错误不会自动消失。

### 5.8 空状态与首次使用

首次打开时，网站区不放「示例网站」，而是一张轻量卡片：「添加第一个网站」「从浏览器书签导入」「选一个主题」「用 AI 生成一个主页」。用户执行任意一项后，卡片永久消失。

## 6. 图标与图像

- **界面图标**：Lucide（ISC 许可），描边 1.5px，尺寸 16 / 20 / 24px，颜色继承 `currentColor`，不混用其他图标库。
- **壁纸处理**：提供遮罩（暗化 0–80%）、模糊（0–40px）、灰度、晕影（借鉴 nightTab 的 vignette）、缩放。系统根据壁纸平均亮度自动建议深色或浅色文字，用户可以覆盖。
- **壁纸上的可读性**：有壁纸时，时钟和网站名自动加极淡的文字阴影 `0 1px 12px rgb(0 0 0 / .25)`，用户可关闭。
- **背景类型**：纯色、渐变（2–3 个色标，角度可调）、本地图片、强调色、（后续）本地视频。

---

## 7. 动效细则

- 允许：悬停微移、开关滑动、菜单淡入加 4px 位移、抽屉滑入、主题切换时 200ms 颜色过渡、拖动重排时的位移动画。
- 禁止：常驻动画（呼吸灯、背景粒子）、视差、入场序列动画、强调色循环（nightTab 的 accent cycle 不默认提供，只作为实验项，且受减少动画设置约束）。

---

## 8. 无障碍与质量护栏

1. 所有交互元素都有可见焦点；只有图标的按钮必须有 `aria-label`。
2. 对比度检查自动运行于：手动改色、应用预设、导入主题包。不达标时给出警告并提供「一键修正」：在 OKLCH 中只调整亮度，直到达标。
3. 遵守 `prefers-reduced-motion`、`prefers-reduced-transparency`、`prefers-color-scheme`（主题模式可选「跟随系统」）。
4. 最小点击区域 32×32px（网站图标本身更大）。
5. 文字可放大到 200% 不重叠；网站名截断而不是换行挤压。
6. 用户 CSS 无法隐藏设置入口和安全模式入口（PLAN §4.6）。

## 10. 给 AI 的设计约束（嵌入提示包）

> 以下内容会原样放进「AI 提示包」，用中英双语维护。

**必须：**
- 只使用 `--mnt-*` 变量和 CSS API 中列出的选择器；颜色写在 `theme.color` 中，不要写在 CSS 里。
- 一个强调色；正文对比度 ≥ 4.5:1。
- 优先用主题包的结构化字段（theme / background / layout / widgets）表达意图，只有字段表达不了的效果才写 CSS。
- CSS 保持在 200 行以内，不使用 `!important`。
- 尊重减少动画：任何 `animation` 必须写在 `@media (prefers-reduced-motion: no-preference)` 中。

**不要：**
- 引用外部网址（图片、字体、`@import`）；需要图片时，留空并在 `meta.notes` 中说明让用户自行上传。
- 隐藏或遮挡设置入口；改变 `position` 让组件脱离布局；使用超过 3 种字号。
- 添加用户的个人网站、真实书签或推广链接。
- 使用持续闪烁、旋转、彩虹等动画。

**风格建议（用户未指定时）：**
- 留白多于内容；时钟或搜索二选一作为视觉焦点。
- 背景饱和度低（OKLCH C < 0.06），强调色可稍高（C 0.08–0.16）。
- 字距：大号数字收紧，小号大写英文放宽。
