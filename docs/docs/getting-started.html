Getting started

Choose where to use Promptab

The extension and web app keep separate profiles. Pick the setup that fits your browser, then use a backup file when you want to move data between them.

Microsoft Edge

For a local development install, use Node.js 22 and npm in the project folder:

npm ci
npm run build

Open edge://extensions, enable Developer mode, choose Load unpacked, and select the generated dist folder. Confirm the new-tab change if Edge asks. Rebuild and reload the extension after updating it. The Edge Add-ons listing is under review; use the store listing when it becomes available.

Google Chrome

Build with the same commands above, then open chrome://extensions. Enable Developer mode, choose Load unpacked, and select dist. Chrome may ask you to confirm the new-tab override.

Firefox for desktop

Build the Firefox package and load it temporarily:

npm run build:firefox

Open about:debugging#/runtime/this-firefox, choose Load Temporary Add-on, and select dist-firefox/manifest.json. A temporary add-on is removed when Firefox closes. The AMO listing is not available yet. This package targets desktop Firefox; mobile support is not declared.

Web app

Open Promptab on the web in a supported browser. On iPhone or iPad, use Safari’s Share menu and choose Add to Home Screen. On Android, open the page in Chrome and choose Install app or Add to Home screen from the browser menu.

The web shell is cached for offline use after it has loaded. Some features that require extension APIs, including browser sync and bookmark import, are unavailable on the web.

Move a setup with a backup

  1. In the source version, open Settings → Data → Export backup.
  2. Save the backup file somewhere you control. It contains your profiles and the assets they use.
  3. Open the other version, choose Settings → Data → Import backup, and select the file. Import validates it before applying it. Choose which parts to restore; all parts are selected initially.

Extension and web storage are separate. Uninstalling an extension may remove its browser-managed data, so export a backup first and keep the file outside the browser.

Share a theme without your personal data

Open Settings → AI → Export theme pack to download a shareable JSON theme or copy it as an AI reply. The pack excludes bookmarks, profile and sync details, API keys, weather location, and local wallpaper, video, and font files. Portable custom CSS is kept; declarations that refer to local assets are removed and counted in the export dialog. You can also exclude all custom CSS. The download filename is based on the theme name. To submit a theme to the gallery, attach the downloaded JSON and a preview screenshot.

A theme pack shares appearance settings, while a backup moves your full setup, including profiles, assets, and your saved themes. Saved themes stay local and are not part of Browser Sync.

Choose how your new tab behaves

In Settings → Appearance, choose independently whether shortcut links and search results open in new tabs. Save up to 50 themes in My themes; preview one, apply it through the preview banner, and undo the change if you want to return.

Accent on open can stay off, choose a random accent, or cycle through the palette each time a tab opens. This changes runtime colors without adding profile history or sync writes. Press / for search, E to edit, A to add a shortcut, , for settings, D to switch theme mode, and ? for keyboard help. Disable these shortcuts in Appearance if you prefer.

Personalize the date and greeting

In Settings → Widgets, enable the date's week number and choose when the week starts. Add a greeting there, then use its Layout controls to show an optional weekday and time-of-day line. The extra line is off by default.

快速开始

选择使用 Promptab 的方式

扩展与网页版使用独立配置。选择适合你浏览器的方式；需要在两者间迁移时，可以使用备份文件。

Microsoft Edge

如需本地开发安装，请在项目目录中使用 Node.js 22 和 npm：

npm ci
npm run build

打开 edge://extensions，启用开发人员模式，选择加载解压缩的扩展，再选择生成的 dist 文件夹。若 Edge 提示，请确认更改新标签页。更新代码后重新构建并加载扩展。Edge Add-ons 商店上架仍在审核中；正式上线后可使用商店版本。

Google Chrome

使用上面的命令构建，然后打开 chrome://extensions。启用开发者模式，选择加载已解压的扩展程序并选择 dist。Chrome 可能会提示确认新标签页更改。

桌面版 Firefox

构建 Firefox 版本并临时加载：

npm run build:firefox

打开 about:debugging#/runtime/this-firefox，选择临时载入附加组件，并打开 dist-firefox/manifest.json。临时附加组件会在 Firefox 关闭后移除。AMO 商店版本尚未上架。此构建面向桌面版 Firefox，未声明支持移动版。

网页版

在支持的浏览器中打开 Promptab 网页版。在 iPhone 或 iPad 上使用 Safari 的分享菜单并选择添加到主屏幕。在 Android 上用 Chrome 打开，然后从浏览器菜单选择安装应用或添加到主屏幕。

首次加载后，网页版应用外壳会缓存以供离线使用。浏览器同步和书签导入等依赖扩展 API 的功能无法在网页版使用。

使用备份迁移配置

  1. 在来源版本中打开设置 → 数据 → 导出备份。
  2. 将备份文件保存在你能管理的位置。文件包含配置文件及其使用的资源。
  3. 在另一个版本中选择设置 → 数据 → 导入备份并选中文件。导入前会先校验内容。你可以选择恢复哪些部分；默认全部选中。

扩展和网页版的数据彼此独立。卸载扩展可能会清除浏览器管理的数据，因此请先导出备份，并将文件保存在浏览器之外。

分享主题，不分享个人数据

打开设置 → AI → 导出主题包，即可下载可分享的 JSON 主题，或将其复制为 AI 回复。主题包会排除书签、个人资料和同步信息、API 密钥、天气位置，以及本地壁纸、视频和字体文件。可移植的自定义 CSS 会保留；引用本地资源的声明会被移除，导出对话框会显示移除数量。你也可以排除全部自定义 CSS。下载文件名根据主题名称生成。提交主题到画廊时，请附上下载的 JSON 和预览截图。

主题包用于分享外观设置；备份用于迁移完整配置，包括配置文件、资源和已保存的主题。主题保存在本机，不属于浏览器同步内容。

设置新标签页行为

在设置 → 外观中，可分别设置快捷方式链接和搜索结果是否在新标签页打开。在我的主题中最多保存 50 个主题；你可以先预览，再通过预览横幅应用，也可以撤销更改。

打开时的强调色可保持关闭、随机选择，或在每次打开标签页时按调色板循环切换。颜色只在运行时变化，不会增加配置历史或写入同步数据。按 / 聚焦搜索，按 E 编辑，按 A 添加快捷方式，按 , 打开设置，按 D 切换主题模式，按 ? 查看键盘帮助。如不需要，可在“外观”中关闭这些快捷键。

自定义日期和问候语

在设置 → 小组件中启用日期周数并选择一周从哪天开始。也可在此添加问候语，然后在布局控制中启用显示星期和时段的附加语句。附加语句默认关闭。
