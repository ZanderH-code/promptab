Cascade layers

The built-in order is guard → reset → tokens → base → widgets → theme → user. User CSS is wrapped in @layer user, so ordinary user declarations come after the built-in layers. The earlier guard layer uses important declarations to keep the settings entry and banners usable.

Sanitizer rules

Valid CSS is parsed, comments are removed, and the result is normalized before it is injected. Invalid CSS is rejected as a whole and is not injected. Limits are 65,536 bytes and 2,000 rules.

  • Allowed at-rules: @media · @supports · @keyframes · @-webkit-keyframes · @font-face · @container · @layer · @property. Other at-rules, including @import, are rejected.
  • Rejected properties: -moz-binding、behavior. Rejected functions: expression()、url(). External or unrecognized URLs are rejected; accepted references are local mnt-asset: assets, data:image/ values, and fragment references. In @font-face, only local mnt-asset: font files are accepted. URL-bearing string functions checked include image-set()、-webkit-image-set()、image()、src()、cross-fade()、-webkit-cross-fade().
  • Unbalanced syntax, parser errors, escaped names, disallowed raw values, and rule-limit violations block the stylesheet.
  • !important is parsed but discouraged: it can make later theme adjustments ineffective. The AI workbench reports it as a warning.

The guard layer protects the settings entry and banners. If custom CSS makes the settings entry unreachable, the reach check removes the CSS so you can recover.

Safe mode

Open the page with #safe in the URL or press Escape three times quickly. Safe mode pauses custom CSS but leaves the editor available. Turn safe mode off from its banner after fixing or removing the problematic rules.

层叠层级

内置层级顺序为 guard → reset → tokens → base → widgets → theme → user。用户 CSS 会包裹在 @layer user 中，因此普通用户声明位于内置层之后。更早的 guard 保护层使用 important 声明，确保设置入口和横幅可用。

清理规则

有效 CSS 会经过解析、移除注释并规范化后再注入。无效 CSS 会整体拒绝，不会注入。限制为 65,536 字节和 2,000 条规则。

  • 允许的 at-rule：@media · @supports · @keyframes · @-webkit-keyframes · @font-face · @container · @layer · @property。其他 at-rule（包括 @import）都会拒绝。
  • 拒绝的属性：-moz-binding、behavior。拒绝的函数：expression()、url()。外部或无法识别的网址会被拒绝；允许本地 mnt-asset: 资源、data:image/ 值和片段引用。在 @font-face 中只允许本地 mnt-asset: 字体文件。会检查的 URL 字符串函数包括 image-set()、-webkit-image-set()、image()、src()、cross-fade()、-webkit-cross-fade()。
  • 不平衡语法、解析器错误、转义名称、不允许的原始值以及超出规则数量上限都会阻止样式表加载。
  • 解析器允许 !important，但不建议使用：它可能阻碍后续主题调整。AI 工作台会对此发出警告。

保护层确保设置入口和横幅保持可用。如果自定义 CSS 让设置入口无法访问，可达性检查会移除整份 CSS，方便你恢复。

安全模式

在网址后加 #safe，或快速连续按三次 Escape。安全模式会暂停自定义 CSS，但编辑器仍可使用。修复或移除问题规则后，可在安全模式横幅中退出。
