Theme pack v2

A theme pack is a JSON object. The optional kind and packVersion markers identify the format; when present, they must be mnt.theme-pack and 2. The JSON Schema is generated from the same Zod schema used by the app. Every content part is optional. When a field has no schema default, the table says so; applying a partial pack leaves omitted parts and fields on the active profile unchanged.

Colors use hex values. Numeric ranges are inclusive. Required nested fields become required when their containing object is present. Bookmarks and wallpaper images are never applied from a theme pack.

Shareable exports

When a theme pack is exported from the AI workbench, personal data and local wallpaper, video, and font files are omitted. Portable custom CSS is retained; declarations that reference local assets are removed, and the export dialog reports the number removed. The dialog also offers an option to omit all custom CSS. Downloaded JSON filenames are based on the pack name.

How partial packs apply

Theme values merge with the current theme. Missing surfaces are derived from supplied colors; font fields merge individually. Background fields merge. Layout fields merge, breakpoint entries merge, and a supplied area-style map replaces the previous map. Widgets with matching IDs and types merge their props; new widget IDs are appended. Supplied CSS replaces and enables custom CSS. Supplied variables replace variable declarations; compatible values are retained only for the same named source pack. See the AI workflow for safe preview and apply.

可分享的导出文件

从 AI 工作台导出主题包时，会省略个人数据以及本地壁纸、视频和字体文件。可移植的自定义 CSS 会保留，引用本地资源的声明会被移除，导出对话框会显示移除数量。对话框也提供排除全部自定义 CSS 的选项。下载的 JSON 文件名根据主题包名称生成。

部分主题包如何应用

主题数值会与当前主题合并。未提供的表面颜色会从已提供颜色推导；字体字段逐项合并。背景字段会合并。布局字段会合并，断点网格逐项合并，已提供的区域样式表会整体替换旧表。ID 和类型匹配的组件会合并属性；新的组件 ID 会追加。提供的 CSS 会替换并启用自定义 CSS。提供的变量会替换变量声明；只有来自同名主题包的兼容值会保留。请参阅AI 工作流程，先预览再应用。
