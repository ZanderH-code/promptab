Design with your AI

Prompt, paste, preview, apply

Promptab gives you a portable theme brief and validates the reply. Your chosen assistant does the creative work; Promptab does not operate an AI service.

  1. Copy the prompt pack. In a new tab, open Settings → AI, describe the result you want, then choose Copy prompt pack. Including your current theme and CSS is optional; bookmarks are excluded.
  2. Ask an assistant you already use. Paste the prompt into ChatGPT, Claude, Kimi, DeepSeek, or another assistant. Ask for one complete JSON or CSS code block and remind it to keep personal bookmarks out.
  3. Paste the full reply. Return to Promptab and paste the response into The AI's reply, or open a local JSON/CSS/Markdown file. Review any corrections and warnings.
  4. Choose, preview, then apply. Select which theme parts to keep. Preview first; the preview is temporary. Apply only when it looks right. You can undo an applied change.

Optional: send directly with BYOK

The workbench can send a prompt directly from your browser to Anthropic or OpenAI using a key you provide for that page session. This is optional; copy-and-paste works with any assistant. The key stays in page memory and is cleared when the session ends. The chosen provider receives your prompt and handles it under its own terms; API charges may apply. See the privacy page before enabling direct sending.

用你的 AI 设计

描述、粘贴、预览、应用

Promptab 会生成可迁移的主题说明并校验 AI 回复。创意由你选择的助手完成；Promptab 本身不运营 AI 服务。

  1. 复制提示包。在新标签页打开设置 → AI，描述你想要的效果，然后选择复制提示包。是否加入当前主题和 CSS 由你决定；书签不会包含在内。
  2. 询问你正在使用的助手。将提示词粘贴到 ChatGPT、Claude、Kimi、DeepSeek 或其他助手中。请它返回一个完整的 JSON 或 CSS 代码块，并提醒它不要加入私人书签。
  3. 粘贴完整回复。回到 Promptab，将回复粘贴到AI 的回复中，或打开本地 JSON/CSS/Markdown 文件。检查自动修正和警告。
  4. 选择、预览，再应用。选择要保留的主题部分。先预览；预览是临时的。确认效果后再应用，应用后可以撤销。

可选：使用 BYOK 直连

工作台可以使用你为当前页面会话提供的密钥，从浏览器直接向 Anthropic 或 OpenAI 发送提示词。这不是必需步骤；复制粘贴适用于任何助手。密钥只保存在页面内存中，会话结束后清除。所选服务商会收到提示词，并依据其条款处理；API 使用可能收费。启用直连前，请阅读隐私页面。
