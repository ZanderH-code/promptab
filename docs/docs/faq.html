FAQ

Good to know

Does Promptab collect my data?

Promptab has no account system, analytics, telemetry, or developer-operated app server. Your extension profile stays in browser-managed extension storage. The web app uses that site's local storage and IndexedDB, separate from the extension. Some features you choose contact the relevant service directly, such as search, weather, gallery downloads, remote images, or an AI provider you call with BYOK. See the privacy policy for details.

Why does the extension ask for permissions?

Storage permissions keep profiles, settings, and local assets in the browser. The optional bookmarks permission is requested only when you start browser bookmark import; Promptab reads the tree to show choices and copies only what you select. It does not monitor bookmarks continuously. Optional host access is used by features you explicitly choose, including direct BYOK requests and weather. The web app cannot request extension permissions.

What does Browser Sync send?

Browser Sync is an extension-only option and is off by default. If you enable it, profile shortcuts and groups, theme settings, layout, and update metadata are written to the browser's sync storage. Saved themes, wallpaper/video, uploaded fonts, and bookmark images stay local. The browser provider processes sync data under its own account terms. Use a full backup to move a complete setup, including saved themes, between the web app and extension.

Why can't a mobile browser replace its new-tab page?

Mobile browsers generally do not expose the desktop extension API that lets an extension override the new-tab page. Promptab's web version works on mobile and can be added to the home screen, but it opens as a web app rather than replacing the browser's new tab. Firefox for Android may install some add-ons, but this extension does not declare mobile support or a new-tab override there.

Can I share my theme without sharing my bookmarks?

Yes. In Settings → AI, choose Export theme pack to download a JSON file or copy it as a fenced AI reply. Theme packs include appearance settings and portable CSS, but omit bookmarks, profile identity, sync state, API keys, weather location, and local wallpaper, video, or font files. CSS declarations that reference local assets are removed while other portable declarations are kept; the export dialog reports how many declarations were removed and lets you exclude all custom CSS. The download uses a filename based on the theme name. For the gallery, attach the downloaded JSON and a preview screenshot; the submission link does not contain the pack.

Do saved themes sync?

No. My themes stays on this device and is not included in Browser Sync. A full backup includes the saved theme library; a theme pack export shares one portable theme.

How do the new-tab shortcuts and accent modes work?

Shortcut links and search results have independent settings for opening in new tabs. Press / to focus search, E to toggle editing, A to add a shortcut, , to open settings, D to switch light and dark, or ? for help. These keys do nothing while you type, and keyboard shortcuts can be disabled in Appearance. Accent on open can stay off, choose a random palette accent, or cycle through the palette; these runtime changes do not create profile history or sync writes.

Can I restore only part of a backup?

Yes. After choosing a backup, select the parts you want to restore. All parts are selected by default; for a partial restore, the selected content comes from the backup's active profile.

How are week numbers calculated?

Enable the date widget's week number in Settings → Widgets and choose the first day of the week. Monday uses ISO week numbering; Sunday and Saturday number the week containing January 1 as week 1. The default follows the interface language.

Can I use Promptab without connecting an AI account?

Yes. The extension includes themes and a gallery, and the AI workbench uses copy and paste with any assistant. BYOK direct sending is optional. Promptab itself does not provide AI credits or send prompts on its own.

What if custom CSS makes the page hard to use?

Open the page with #safe in the address, or press Escape three times quickly. Safe mode pauses custom CSS so you can edit or remove it. Read the CSS API reference before using custom selectors.

常见问题

使用前须知

Promptab 会收集我的数据吗？

Promptab 没有账号系统、分析、遥测或开发者运营的应用服务器。扩展配置保存在浏览器管理的扩展存储中。网页版使用该网站的本地存储和 IndexedDB，与扩展分开。你主动使用的部分功能会直接联系对应服务，例如搜索、天气、画廊下载、远程图片，或通过 BYOK 调用的 AI 服务。详情请阅读隐私政策。

扩展为何请求权限？

存储权限用于在浏览器中保存配置、设置和本地资源。可选的 bookmarks 权限只会在你开始导入浏览器书签时请求；Promptab 读取书签树以供选择，并只复制你选中的内容，不会持续监控书签。可选主机权限用于你主动选择的功能，包括 BYOK 直连和天气。网页版无法请求扩展权限。

浏览器同步会发送什么？

浏览器同步仅适用于扩展，默认关闭。启用后，配置中的快捷方式和分组、主题设置、布局及更新时间会写入浏览器同步存储。我的主题库、壁纸/视频、上传的字体和书签图片仍保存在本地。同步数据由浏览器服务商依据账号条款处理。若要在网页版与扩展之间迁移完整配置（包括已保存的主题），请使用完整备份。

为什么移动浏览器不能替换新标签页？

移动浏览器通常不开放桌面扩展所需的 API，因此扩展无法接管浏览器的新标签页。Promptab 网页版可在移动设备使用，也可添加到主屏幕，但它作为网页应用打开，不会替换浏览器的新标签页。Firefox for Android 可以安装部分附加组件，但此扩展未声明支持移动端或在该浏览器中接管新标签页。

分享主题时会连书签一起分享吗？

不会。在设置 → AI中选择导出主题包，即可下载 JSON 文件，或将其复制为带代码围栏的 AI 回复。主题包包含外观设置和可移植 CSS，但不包含书签、个人资料身份、同步状态、API 密钥、天气位置，以及本地壁纸、视频或字体文件。引用本地资源的 CSS 声明会被移除，其他可移植声明会保留；导出对话框会报告移除数量，也可以选择排除全部自定义 CSS。下载文件名会根据主题名称生成。提交到画廊时，请附上下载的 JSON 和预览截图；提交链接本身不包含主题包。

已保存的主题会同步吗？

不会。“我的主题”保存在本机，不会通过浏览器同步发送。完整备份会包含主题库；导出主题包则用于分享单个可移植主题。

新标签页快捷键和强调色模式如何使用？

快捷方式链接和搜索结果可分别设置为在新标签页打开。按 / 聚焦搜索，按 E 切换编辑，按 A 添加快捷方式，按 , 打开设置，按 D 切换浅色和深色，按 ? 查看帮助。输入文字时这些快捷键不会触发，也可在“外观”中关闭键盘快捷键。打开时的强调色可保持关闭、随机选择或按主题调色板循环切换；这些运行时变化不会创建配置历史，也不会写入同步数据。

可以只恢复备份的一部分吗？

可以。选择备份文件后，勾选要恢复的部分，默认全部选中。部分恢复使用备份中当前配置的所选内容。

周数如何计算？

在“设置 → 小组件”中启用日期的周数，并选择每周的第一天。选择周一时采用 ISO 周数；选择周日或周六时，包含 1 月 1 日的一周为第 1 周。默认值随界面语言变化。

不连接 AI 账号也能用 Promptab 吗？

可以。扩展内置主题和画廊，AI 工作台支持复制提示词并粘贴任何助手的回复。BYOK 直连是可选功能。Promptab 不提供 AI 额度，也不会自行发送提示词。

自定义 CSS 影响使用时怎么办？

在地址中打开带有 #safe 的页面，或快速连续按三次 Escape。安全模式会暂停自定义 CSS，你可以编辑或移除它。使用自定义选择器前，请阅读 CSS API 参考。
