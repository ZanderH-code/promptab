FAQ

Good to know

Does Promptab collect my data?

Promptab has no account system, analytics, telemetry, or developer-operated app server. Your extension profile stays in browser-managed extension storage. The web app uses that site's local storage and IndexedDB, separate from the extension. Some features you choose contact the relevant service directly, such as search, weather, gallery downloads, remote images, or an AI provider you call with BYOK. See the privacy policy for details.

Why does the extension ask for permissions?

Storage permissions keep profiles, settings, and local assets in the browser. The optional bookmarks permission is requested only when you start browser bookmark import; Promptab reads the tree to show choices and copies only what you select. It does not monitor bookmarks continuously. Optional host access is used by features you explicitly choose, including direct BYOK requests and weather. The web app cannot request extension permissions.

What does Browser Sync send?

Browser Sync is an extension-only option and is off by default. If you enable it, profile shortcuts and groups, theme settings, layout, and update metadata are written to the browser's sync storage. Wallpaper/video, uploaded fonts, and bookmark images stay local. The browser provider processes sync data under its own account terms. Use a backup file to move a complete setup between the web app and extension.

Why can't a mobile browser replace its new-tab page?

Mobile browsers generally do not expose the desktop extension API that lets an extension override the new-tab page. Promptab's web version works on mobile and can be added to the home screen, but it opens as a web app rather than replacing the browser's new tab. Firefox for Android may install some add-ons, but this extension does not declare mobile support or a new-tab override there.

Can I use Promptab without connecting an AI account?

Yes. The extension includes themes and a gallery, and the AI workbench uses copy and paste with any assistant. BYOK direct sending is optional. Promptab itself does not provide AI credits or send prompts on its own.

What if custom CSS makes the page hard to use?

Open the page with #safe in the address, or press Escape three times quickly. Safe mode pauses custom CSS so you can edit or remove it. Read the CSS API reference before using custom selectors.

常见问题

使用前须知

Promptab 会收集我的数据吗？

Promptab 没有账号系统、分析、遥测或开发者运营的应用服务器。扩展配置保存在浏览器管理的扩展存储中。网页版使用该网站的本地存储和 IndexedDB，与扩展分开。你主动使用的部分功能会直接联系对应服务，例如搜索、天气、画廊下载、远程图片，或通过 BYOK 调用的 AI 服务。详情请阅读隐私政策。

扩展为何请求权限？

存储权限用于在浏览器中保存配置、设置和本地资源。可选的 bookmarks 权限只会在你开始导入浏览器书签时请求；Promptab 读取书签树以供选择，并只复制你选中的内容，不会持续监控书签。可选主机权限用于你主动选择的功能，包括 BYOK 直连和天气。网页版无法请求扩展权限。

浏览器同步会发送什么？

浏览器同步仅适用于扩展，默认关闭。启用后，配置中的快捷方式和分组、主题设置、布局及更新时间会写入浏览器同步存储。壁纸/视频、上传的字体和书签图片仍保存在本地。同步数据由浏览器服务商依据账号条款处理。若要在网页版与扩展之间迁移完整配置，请使用备份文件。

为什么移动浏览器不能替换新标签页？

移动浏览器通常不开放桌面扩展所需的 API，因此扩展无法接管浏览器的新标签页。Promptab 网页版可在移动设备使用，也可添加到主屏幕，但它作为网页应用打开，不会替换浏览器的新标签页。Firefox for Android 可以安装部分附加组件，但此扩展未声明支持移动端或在该浏览器中接管新标签页。

不连接 AI 账号也能用 Promptab 吗？

可以。扩展内置主题和画廊，AI 工作台支持复制提示词并粘贴任何助手的回复。BYOK 直连是可选功能。Promptab 不提供 AI 额度，也不会自行发送提示词。

自定义 CSS 影响使用时怎么办？

在地址中打开带有 #safe 的页面，或快速连续按三次 Escape。安全模式会暂停自定义 CSS，你可以编辑或移除它。使用自定义选择器前，请阅读 CSS API 参考。
