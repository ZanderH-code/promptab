Privacy policy

Promptab is a browser new-tab extension. Its developer does not collect user data. Promptab has no account system, advertising SDK, analytics, telemetry, or developer-operated application server.

Data on your device

Settings, profiles, bookmarks and shortcuts, layouts, themes, custom CSS, imported themes, and locally added images and fonts are stored in browser-managed storage on your device. The unlimitedStorage permission allows larger local profiles and assets. When run as a development or preview web app, Promptab may use local storage instead. It does not send saved data to a developer-operated service.

Optional bookmark access

The bookmarks permission is optional and requested only when you start browser-bookmark import. If granted, Promptab reads the bookmark tree to show available folders, then copies the folders and links you select into its local profile. It does not continuously monitor bookmarks. If you decline, other features remain available.

Network requests and navigation

Features you choose can contact other services directly:

  • Automatic website icons use the browser's favicon endpoint when available. The fallback requests /favicon.ico from the shortcut's website, so that website can receive the request. Choose a custom or manually selected icon to avoid these favicon requests.
  • Searches navigate to your selected provider with your query; opening a shortcut contacts that website.
  • Remote wallpapers or imported remote images are fetched from their configured URLs; their hosts can receive the requests.

These services have their own privacy policies. Promptab does not use these requests for analytics or sell personal information.

Backups and AI

Backups and exports are created only when you request them. The AI workbench prepares and validates data locally and has no built-in AI network client. If you share content with an AI service yourself, that service's policy applies.

Deleting data and policy changes

Use the extension's reset or delete controls, or your browser's extension storage controls, to remove data. Uninstalling removes browser-managed extension storage subject to browser behavior; exported files remain wherever you saved them. This policy may change when data practices change. The Promptab repository provides project contact details.

隐私政策

Promptab 是一款浏览器新标签页扩展。开发者不收集用户数据；扩展不包含账号系统、广告 SDK、分析、遥测或开发者运营的应用服务器。

设备上的数据

设置、配置、书签和快捷方式、布局、主题、自定义 CSS、导入的主题以及本地添加的图片和字体，保存在设备上的浏览器管理存储中。unlimitedStorage 权限用于支持较大的本地配置和资源。作为开发或预览网页运行时，Promptab 也可能使用本地存储。扩展不会将保存的数据发送给开发者运营的服务。

可选书签权限

bookmarks 是可选权限，仅在你开始导入浏览器书签时请求。授权后，Promptab 会读取书签树以展示可选文件夹，并将你选择的文件夹和链接复制到扩展的本地配置中；扩展不会持续监控书签。拒绝授权不影响其他功能。

网络请求与访问网站

你选择使用的功能可能直接联系其他服务：

  • 自动网站图标优先使用浏览器的 favicon 接口；后备方式会请求快捷方式网站的 /favicon.ico，因此该网站可能收到请求。选择自定义图标或手动指定图标可避免这些 favicon 请求。
  • 搜索会携带查询内容跳转到你选择的搜索服务；打开快捷方式会访问相应网站。
  • 远程壁纸或导入的远程图片会从配置的网址获取，相应主机可能收到请求。

这些服务适用各自的隐私政策。Promptab 不使用这些请求进行分析，也不出售个人信息。

备份与 AI

备份和导出只在你主动操作时生成。AI 工作台在本地准备和校验数据，没有内置 AI 网络客户端。如果你自行向 AI 服务分享内容，该服务的隐私政策适用。

删除数据与政策变更

你可以通过扩展的重置或删除控件，或浏览器的扩展存储控件删除数据。卸载扩展会删除浏览器管理的扩展存储，具体取决于浏览器行为；你导出的文件仍保留在保存位置。如果数据处理方式发生变化，本政策可能更新。项目联系信息见 Promptab 仓库。
