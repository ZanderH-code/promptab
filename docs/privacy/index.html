Privacy policy

Promptab is available as a browser extension and a separately hosted web app. The developer does not collect user data. Promptab has no account system, advertising SDK, analytics, telemetry, or developer-operated application server.

Extension and web data are separate

The extension stores settings and preferences (including keyboard shortcuts and accent behavior), profiles, bookmarks and shortcuts, layouts, themes, custom CSS, saved and imported themes, and locally added images and fonts in browser-managed extension storage. The web version stores its settings in that website's local storage and its larger assets in browser-local IndexedDB. These stores are separate: using the same browser does not automatically share settings between the extension and web app. These features do not contact a Promptab service. Saved themes stay local and are not part of Browser Sync.

To migrate between versions, export a backup from Settings → Data → Export backup, save the file, then use the other version's import control. Import validates the backup before applying it. Infinity New Tab backups are read locally in the active page; remote image references and cloud wallpapers in those files are not downloaded. Backups are files you control; protect or delete them as you choose. Extension-only features such as Browser Sync and browser bookmark import are unavailable on the web version because it has no extension permission APIs.

Optional extension bookmark access

The extension's bookmarks permission is optional and requested only when you start browser-bookmark import. If granted, Promptab reads the bookmark tree to show available folders, then copies the folders and links you select into the extension's local profile. It does not continuously monitor bookmarks. The web version cannot request this extension permission.

Network requests and navigation

Promptab does not run a general data-collection channel. Features you choose can contact other services directly:

  • When automatic icons are enabled, icon discovery runs in the background with at most three concurrent image requests. Chromium can use the browser's favicon endpoint; other candidates are requested from the shortcut site's own origin: /apple-touch-icon.png, /apple-touch-icon-precomposed.png, /favicon.svg, /favicon-32x32.png, and /favicon.ico. For a small bundled list of known sites (about twenty), Promptab may also request the official icon URLs listed in that list, which can be on the site's own origin or on a CDN such as Google gstatic, Microsoft onecdn, TradingView static, or CoinMarketCap static hosts. Some known sites display a bundled brand icon without making any request. These requests tell the relevant website or CDN that an icon was requested. The best result, a brand result, or a failure is cached separately per site under mnt.iconCache:v2 (success: 7 days; failure: 1 hour), in extension storage.local or, on the web, localStorage. Sites with a product path, such as Google Maps, keep a separate entry for that path. This cache is not part of profiles, backups, or sync. The web version does not have the extension favicon endpoint; opening shortcuts also contacts their websites.
  • Searches navigate to your selected provider with your query. Wallpaper and shortcut images are managed locally; Promptab does not fetch remote wallpaper or shortcut-image URLs.
  • Opening the theme gallery fetches its list from zanderh-code.github.io; selecting a theme fetches its pack from the same host. The list is cached locally for offline browsing.
  • The optional weather widget contacts Open-Meteo only after you use a weather action. City search sends the city name to geocoding-api.open-meteo.com; loading weather sends coordinates to api.open-meteo.com. Location is requested only after you click its button, with no background tracking. Weather is cached locally for at least 30 minutes.
  • If you choose direct BYOK sending, the browser sends your prompt, selected model, and API key directly to api.anthropic.com or api.openai.com. The web app makes these requests from the browser without a Promptab relay. Anthropic requests include the anthropic-dangerous-direct-browser-access: true header required for direct browser requests; OpenAI requests use bearer authentication. The provider receives the request and handles it under its own terms and privacy policy; API charges may apply.

BYOK keys are held only in the active page session's memory. They are not written to browser storage or uploaded to Promptab, and are cleared when the page session ends. Promptab does not use feature requests for analytics or sell personal information.

Browser Sync and deletion

Browser Sync is an extension-only feature and is off by default. If enabled, profile preferences (including keyboard-shortcut and accent-on-open settings), shortcut/group data, theme settings, layout and update metadata are written to chrome.storage.sync, which Chrome processes for your signed-in browser account under Google's terms. Saved themes, wallpaper, video, uploaded fonts and bookmark images stay local and are not synced. The web version does not support Browser Sync. Use each version's reset controls or the browser's site/extension data controls to remove local data. Uninstalling removes extension storage subject to browser behavior; exported backups remain wherever saved. This policy may change when data practices change. The Promptab repository provides project contact details.

隐私政策

Promptab 提供浏览器扩展和单独托管的网页版。开发者不收集用户数据；Promptab 不包含账号系统、广告 SDK、分析、遥测或开发者运营的应用服务器。

扩展与网页版数据分开保存

扩展将设置、配置文件、书签和快捷方式、布局、主题、自定义 CSS、导入的主题以及本地添加的图片和字体保存在设备的浏览器扩展存储中。网页版将设置保存在该网站的本地存储中，并将较大的资源保存在浏览器本地 IndexedDB 中。两者使用独立存储；即使在同一浏览器中使用，也不会自动共享配置。保存的数据不会发送给 Promptab 服务器。

如需在两个版本之间迁移，请在「设置 → 数据 → 导出备份」中导出并保存文件，再在另一个版本中使用导入功能。导入前会校验备份。Infinity New Tab 备份只在当前页面本地解析；文件中的远程图片引用和云端壁纸不会被下载。备份文件由你自行保管或删除。浏览器同步和浏览器书签导入仅适用于扩展，网页版没有扩展权限 API，无法使用这些功能。

扩展的可选书签权限

扩展的 bookmarks 是可选权限，仅在你开始导入浏览器书签时请求。授权后，Promptab 会读取书签树以展示可选文件夹，并将你选择的文件夹和链接复制到扩展本地配置中；不会持续监控书签。网页版无法请求此扩展权限。

网络请求与访问网站

Promptab 不会通过通用渠道收集数据。你主动使用的功能可能直接联系其他服务：

  • 启用自动网站图标后，图标探测会在后台进行，并发图片请求最多为 3 个。Chromium 可使用浏览器 favicon 接口；其他候选会从快捷方式网站自身的 origin 请求：/apple-touch-icon.png、/apple-touch-icon-precomposed.png、/favicon.svg、/favicon-32x32.png 和 /favicon.ico。对于内置清单中的少量已知网站（约二十个），Promptab 还可能请求该清单列出的官方图标网址；这些网址可能位于网站自身的 origin，也可能位于 Google gstatic、Microsoft onecdn、TradingView static、CoinMarketCap static 等 CDN 主机。部分已知网站直接显示内置品牌图标，不会发出任何请求。这些请求会让相应网站或 CDN 知道有人请求了图标。每个网站的最佳结果、品牌结果或失败结果会按 mnt.iconCache:v2 单独缓存（成功 7 天、失败 1 小时）；扩展保存在 storage.local，网页版保存在 localStorage。带产品路径的网站（例如 Google Maps）会为该路径使用单独条目。缓存不属于配置文件、备份或同步数据。网页版不使用扩展 favicon 接口；打开快捷方式也会访问相应网站。
  • 搜索会携带查询内容跳转到你选择的搜索服务。壁纸和快捷方式图片由本地管理；Promptab 不会获取远程壁纸或快捷方式图片网址。
  • 打开主题画廊时会从 zanderh-code.github.io 获取主题列表；选择主题时会从同一主机获取主题包。列表会缓存在本地，供离线浏览。
  • 可选天气组件只在你使用相关操作后联系 Open-Meteo。城市搜索会向 geocoding-api.open-meteo.com 发送城市名称；加载天气会向 api.open-meteo.com 发送坐标。只有点击定位按钮后才请求位置，不会在后台持续跟踪。天气至少在本地缓存 30 分钟。
  • 如选择 BYOK 直连，你的提示、所选模型和 API 密钥会由浏览器直接发送到 api.anthropic.com 或 api.openai.com，不经过 Promptab 中转。Anthropic 请求会带有其浏览器直连所需的 anthropic-dangerous-direct-browser-access: true 请求头；OpenAI 请求使用 Bearer 身份验证。服务提供商会依据自己的条款和隐私政策处理请求，API 使用可能收费。

BYOK 密钥只保留在当前页面会话的内存中，不写入浏览器存储，也不会上传给 Promptab；页面会话结束后即被清除。Promptab 不使用这些功能请求进行分析，也不出售个人信息。

浏览器同步与数据删除

浏览器同步仅适用于扩展，默认关闭。启用后，配置偏好（包括键盘快捷键和打开时的强调色设置）、快捷方式/分组、主题设置、布局和更新时间会写入 chrome.storage.sync，由 Chrome 根据 Google 条款为你已登录的浏览器账号处理。已保存主题、壁纸、视频、上传的字体和书签图片仍保存在本地，不会同步。网页版不支持浏览器同步。你可以使用各版本的重置控件，或浏览器的站点/扩展数据设置删除本地数据。卸载扩展会删除浏览器管理的扩展存储，具体取决于浏览器行为；导出的备份仍保留在保存位置。如果数据处理方式发生变化，本政策可能更新。项目联系信息见 Promptab 仓库。
