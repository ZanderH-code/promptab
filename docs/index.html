Bring Your Own AI

自带 AI，无需账号与额外付费

Promptab 没有自己的应用服务器，也不锁定特定的模型。它提供开箱即用的提示包与完备的 Schema 契约，让任何你喜欢的 AI 为你排版。

STEP 01
一键复制提示包
打开扩展内的 AI 工作台，输入一两句你的需求（如“极简赛博代码风”），点击一键复制结构化 Prompt。
STEP 02
交给任意 AI 助手
粘贴给你常用的 ChatGPT、Claude、Kimi、DeepSeek 或 Gemini，由它生成标准的主题包数据。
STEP 03
粘贴并实时预览
把 AI 回复全文直接贴回扩展，格式自动容错校验；顶部出现对比横幅，确认满意后一键应用，随时可撤销。
BONUS (BYOK)
直连 API 模式
支持输入你自己的 Anthropic 或 OpenAI Key，密钥仅保留在当前会话内存中，不落盘、不上传，按需直接生成。
Pure Local-First

安全、私密、极致性能

没有账号系统、没有广告 SDK、没有数据埋点。你的数据 100% 留在你的浏览器本地存储中。

⚡
毫秒级首帧加载
非核心代码全部按需异步分包，初始加载仅 ~480KB；首屏零闪烁同步挂载，打开标签页瞬间呈现。
🛡️
受限 CSS 沙箱与安全模式
禁止外部网络 URL 与危险语法；即使自定义样式写崩，只需连按 3 次 Esc 即可无损恢复。
🏷️
全套品牌与通用图标
内置 Simple Icons（CC0）懒加载支持，搭配 Lucide 图标与 Emoji，书签图标自动匹配主题强调色。
📁
浏览器书签与 nightTab 迁移
可按需勾选导入浏览器收藏夹；支持导入经典 nightTab 备份文件，无缝迁移已有配置。
💾
多配置文件与完整备份
工作、生活不同场景一键切换 Profile；完整导出包含所有图片与设置的单文件备份。
⚖️
MIT 开源许可
代码完全独立实现、透明开源；欢迎在 GitHub 提交 Issue、提出新想法或向画廊投稿主题。
