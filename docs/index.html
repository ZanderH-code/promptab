Bring Your Own AI

No Subscription. Zero Lock-In.

Promptab has no proprietary cloud servers and never locks you into a specific model. Use the AI you already love with a clean schema contract.

STEP 01
One-Click Prompt Pack
Open the in-extension AI Workbench, describe what you want in plain words, and click to copy a structured prompt with the schema included.
STEP 02
Chat with Any Assistant
Paste into ChatGPT, Claude, Kimi, DeepSeek, or Gemini. The assistant generates a validated theme pack JSON tailored to your style.
STEP 03
Paste & Live Preview
Paste the reply back. Promptab tolerantly validates and applies a draft preview with instant undo, rollback, and selective applying.
BONUS (BYOK)
Direct API Mode
Optional: Enter your own Anthropic or OpenAI API key. Keys live strictly in temporary session memory and are never persisted or uploaded.
Local-First Architecture

Fast, Private & Open Source

Zero telemetry, zero cookies, and zero external trackers. All configuration and assets live on your local device.

⚡
Instant First Paint
Non-essential modules are loaded on demand. Initial bundle is ~480KB with synchronous theme bootstrap to eliminate startup flash.
🛡️
CSS Sandbox & Safe Mode
Strict parsing blocks external network URLs and dangerous execution. If a custom style breaks, press Esc three times to restore.
🏷️
Brand & General Icons
Built-in Simple Icons (CC0) lazy catalog, Lucide icons, and Emoji support. Icons automatically adapt to your theme's accent color.
📁
Bookmarks & nightTab Import
Selectively import browser bookmark folders via on-demand permission, or migrate seamlessly from classic nightTab backup files.
💾
Multi-Profile & Full Backup
Switch between profiles for work and personal setups with one click. Complete backups include all wallpapers, fonts, and settings.
⚖️
MIT Licensed
Clean, independent implementation with zero proprietary lock-in. Transparent code, community themes, and welcoming contributions.
